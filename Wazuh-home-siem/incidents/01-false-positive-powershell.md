# Incident Report: Alert 92213 - False Positive
[English](#english) | [Русский](#русский)

---

### English

## 1. Alert Details
*   **Rule ID:** 92213
*   **Severity:** Level 15 (Critical)
*   **Description:** Executable file dropped in folder commonly used by malware
*   **MITRE ATT&CK:** T1105 - Ingress Tool Transfer
*   **Agent:** WIN10-PC (192.168.56.110)

## 2. Investigation (Triage)
During routine monitoring, a high-severity alert was triggered by `powershell.exe` creating a file in `C:\Users\Guts\AppData\Local\Temp\`.
*   **Target File:** `__PSScriptPolicyTest_iyj2ouur.jfc.ps1`
*   **Analysis:** OSINT and analysis of Windows internals revealed that this file is automatically generated by PowerShell when it checks execution policies. It is a legitimate system process.
*   **Verdict:** **False Positive**.

## 3. Remediation
To reduce alert fatigue of the SIEM, a custom suppression rule was implemented in `/var/ossec/etc/rules/local_rules.xml`.

*   **Action Taken:** Created Rule ID `100100` with level="0" to ignore file creations matching the regex `__PSScriptPolicyTest_*.ps1`.
```xml
<group name="sysmon,sysmon_eid11_detections,windows,local,">
  <!-- Suppress False Positive for PowerShell Policy Test files -->
  <rule id="100100" level="0">
    <if_sid>92213</if_sid>
    <field name="win.eventdata.targetFilename">\.ps1$</field>
    <field name="win.eventdata.targetFilename">__PSScriptPolicyTest_</field>
    <description>Ignored: Legitimate PowerShell Policy Test file creation (False Positive).</description>
  </rule>
</group>
```

### Русский
# Отчет об инциденте: Alert 92213 - Ложноположительный

## 1. Детали алерта
* **ID правила:** 92213
* **Степень серьезности:** уровень 15 (критический)
* **Описание:** исполняемый файл помещен в папку, обычно используемую вредоносными программами
* **MITRE ATT&CK:** T1105 - Передача средств защиты от проникновения
* **Агент:** WIN10-PC (192.168.56.110)

## 2. Расследование и анализ
Во время рутинного мониторинга при создании файла "powershell.exe" в "C:\Users\Guts\AppData\Local\Temp\" было вызвано предупреждение о высокой степени опасности.
* **Целевой файл:** "__PSScriptPolicyTest_iyj2ouur.jfc.ps1`
* **Анализ:** OSINT и анализ внутренних компонентов Windows показали, что этот файл автоматически генерируется PowerShell при проверке политик выполнения. Это законный системный процесс.
* **Вердикт:** **ложное срабатывание**.

## 3. Устранение неполадок
Чтобы снизить утомляемость от оповещений в SIEM, в "/var/ossec/etc/rules/local_rules.xml" было введено пользовательское правило подавления.

* **Предпринятые действия:** создан идентификатор правила `100100` с level="0", чтобы игнорировать создание файлов, соответствующих регулярному выражению `__PSScriptPolicyTest_*.ps1`.
```xml
<group name="sysmon,sysmon_eid11_detections,windows,local,">
  <!-- Suppress False Positive for PowerShell Policy Test files -->
  <rule id="100100" level="0">
    <if_sid>92213</if_sid>
    <field name="win.eventdata.targetFilename">\.ps1$</field>
    <field name="win.eventdata.targetFilename">__PSScriptPolicyTest_</field>
    <description>Ignored: Legitimate PowerShell Policy Test file creation (False Positive).</description>
  </rule>
</group>
```
